# Research-Paper-Analyzer

## Frontend (ClaimLens)

The web app lives in [`frontend/`](frontend/) and needs Node 20.19+ or 22.12+.

```bash
cd frontend
npm install
npm run dev        # http://localhost:5173
```

It runs without a `.env` file, using the defaults in `frontend/.env.example`. See
[`frontend/README.md`](frontend/README.md) for scripts and environment variables, and
[`docs/FRONTEND_BUILD_PROMPT.md`](docs/FRONTEND_BUILD_PROMPT.md) for the build plan.
